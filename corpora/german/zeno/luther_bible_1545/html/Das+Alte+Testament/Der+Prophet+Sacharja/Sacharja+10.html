X.

1SO bittet nu vom HERRN Spatregen / So wird der HERR gewolcken machen / vnd euch Regen gnug geben / zu allem Gewechse auff dem felde. 2Denn die Götzen reden eitel Mühe / Vnd die Warsager sehen eitel Lügen / vnd reden vergebliche Trewme / Vnd jr trösten ist nichts / Darumb gehen sie in der jrre / wie ein Herd / vnd sind verschmacht / weil kein Hirte da ist. ⇒Mat. 9.

3MEin zorn ist ergrimmet vber die Hirten / vnd ich wil die Böcke1 heimsuchen / Denn der HERR Zebaoth wird seine Herd heimsuchen / nemlich / das haus Juda / Vnd wird sie zurichten / wie ein geschmückt Ross zum streit. 4Die [152a] Ecken / Negel / Streitbogen / vnd Treiber sollen alle von jnen wegkomen. 5Vnd sollen dennoch sein / wie die Risen / die den kot auff der gassen tretten im streit / vnd sollen streiten / Denn der HERR wird mit jnen sein / das die Reuter zuschanden werden. 6Vnd ich wil das haus Juda stercken / vnd das haus Joseph erretten / Vnd wil sie wider einsetzen / Denn ich erbarme mich jr / Vnd sollen sein wie sie waren / da ich sie nicht verstossen hatte / Denn ich der HERR jr Gott wil sie erhören.

7VND Ephraim sol sein / wie ein Rise / vnd jr hertz sol frölich werden / wie vom Wein / Da zu jre Kinder sollens sehen / vnd sich frewen / das jr hertz am HERRN frölich sey. 8Jch wil zu jnen blasen / vnd sie samlen / denn ich wil sie erlösen / Vnd sollen sich mehren / wie sie sich vor gemehret haben. 9Vnd ich wil sie vnter die Völcker seen / das sie mein gedencken in fernen Landen / Vnd sollen mit jren Kindern leben / vnd widerkomen. 10Denn ich wil sie widerbringen aus Egyptenland / vnd wil sie samlen aus Assyrien / vnd wil sie ins land Gilead vnd Libanon bringen / das man sie nicht finden wird. 11Vnd er wird durchs Meer der angst2 gehen / vnd die Wellen im Meer schlahen / das alle tieffe des Wassers vertrocken werden / Da sol denn genidriget werden die pracht zu Assyrien / vnd das Scepter in Egypten sol auffhören.12Jch wil sie stercken in dem HERRN / das sie sollen wandeln in seinem Namen / spricht der HERR. ⇒ Exod. 14.


1 Das sind die Priester vnd Propheten im Volck / die Christus hernach heisst Phariseer.

2 Das heisst das enge Meer / wie sie durch das Rote meer giengen / Durch solchs enge Meer müssen wir alle gehen.


Quelle:
Martin Luther: Die gantze Heilige Schrifft Deudsch. 2 Bände, München 1972.
